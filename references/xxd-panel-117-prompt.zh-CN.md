# Panel 117 运行适配器

每次生成前完整读取 `original-prompt/zh-CN.md`；在原文后追加交付设置，不替换、翻译或改写原文审美。

- `top-bottom`：默认保留原文 3:4 上下交付；明确选择其他尺寸时只改尺寸。上方原图、下方设计，严格各占 50%。
- `left-right`：明确将原文所有交付位置中的“上/下”映射为“左/右”。左原图、右设计，各占一半宽度和整张高度；不再保留上下分区，不增加第三带。细线淡彩审美不变。
- `design-only` / `wallpaper-pack`：整个画布只呈现设计区，照片作为不可见参考；壁纸按已确定的设备尺寸及 `linked` / `independent` 关系分别生成。
- 文字：`prompt`、`exact` 或 `none`，明确目标语种。智能文案来自当前原图，保持细线手写感。样张使用英文，普通任务使用用户确定的语种。
- 尺寸：`auto`、`source`、常用或自定义比例、准确像素；明确尺寸仅覆盖原文画幅要求。
- 输入为单图或递归清点后的目录；每份输出由对应原图独立单轮生成，不将样张或中间转绘结果再次作为输入。
